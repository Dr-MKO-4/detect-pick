Pipeline BiVAT

Prérequis : le pipeline LOF* doit avoir été exécuté pour le même pays/volet.

Architecture du modèle

  • Encodeur BiTransformer : deux passes Transformer (forward + backward) dont les sorties sont concaténées et projetées → capture les dépendances temporelles bidirectionnelles.
  • BiLSTM Bridge : raffine la représentation temporelle avant le décodeur.
  • VAE (Variational Autoencoder) : encode la séquence en espace latent gaussien (μ, σ²) → objective ELBO = reconstruction + β·KL.
  • TransformerDecoder : reconstruit la séquence à partir du vecteur latent.

Score discriminant s_discrim

s_discrim(t) = MSE de reconstruction × Association Discrepancy (AD)
L’AD mesure la divergence KL symétrique entre la distribution d’attention A et une prior gaussienne Q centrée sur chaque token. Une fenêtre anomale présente une haute reconstruction error ET une forte déviation de la prior (concentration d’attention sur des points distants).

Prédiction conforme (CP)

SSBC (Split Conformal + Bootstrap Calibration) : garantit Pr(s ≤ q̂’₀.₅’) ≥ 95% sur données de calibration (2020–2022). Adapté aux petits ensembles (n < 200).
EnbPI : intervalles conformaux rolling (fenêtre 24 mois) sur la période de test. Permet de détecter des ruptures de régime (COVID, chocs externes).

Score hybride (Spec §5)

s_hybrid(t) = 0.5 · LOF*_norm(t) + 0.5 · s_discrim_norm(t)
Combine les deux détecteurs après normalisation min-max. Stocké dans les résultats BiVAT mais non encore affiché séparément — prévu dans une prochaine version.

SHAP (Explainability)

DeepExplainer calcule les valeurs de Shapley pour les top anomalies BiVAT. Le background est constitué de 50 fenêtres normales (score ≤ Q75 du training). Les valeurs SHAP indiquent la contribution de chaque indicateur à l’anomalie détectée.
