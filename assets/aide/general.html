BEAC Anomaly Detector — Guide d’utilisation

Cette application détecte les anomalies dans les agrégats monétaires des six pays membres de la CEMAC (Cameroun, Congo, Gabon, Guinée Équatoriale, RCA, Tchad) en s’appuyant sur deux modèles complémentaires : LOF* et BiVAT.

Flux de travail recommandé

  1. Vérifiez la présence des fichiers de données (Données → icône verte).
  2. Sélectionnez un pays et un volet (Actif / Passif) dans la barre de contrôle.
  3. Choisissez le modèle LOF* et cliquez Lancer l’analyse.
  4. Parcourez les résultats par phase (boutons 1 → 2 → 3).
  5. Pour l’analyse BiVAT (Phase 4), sélectionnez BiVAT après avoir terminé LOF*.
  6. Exportez le rapport via Fichier → Exporter rapport HTML.

Structure des données attendues

Les fichiers doivent être nommés selon le modèle :
clean_{pays}_beac_mapping_2SR_{volet}.xlsx
et placés dans le dossier data/. Chaque fichier contient :
• 195 observations mensuelles (janv. 2001 – mars 2026)
• 55 indicateurs monétaires (masse monétaire, crédit, réserves, etc.)
